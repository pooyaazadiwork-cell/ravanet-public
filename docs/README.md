## Authoritative visual decisions

The selected public palette is:

- background: `#0D0D0D`
- secondary surface: `#303030`
- primary accent: `#B7FF00`
- light text/elements: `#D8D8D8`

The working implementation lives in `src/` and `ro-widget/`. Treat these documents as design inputs—not as permission to replace the existing public funnel or redraw Ro. In particular, retain Ro's large vertical egg-shaped eyes, restrained orbit treatment, original widget behavior, and role as a bridge to human care rather than a therapist or diagnostic system.
